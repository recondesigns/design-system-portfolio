Six product teams. Six ways of solving the same button, the same modal, the same input — with no shared token layer holding any of it together.

Trove closed that gap with a typed token pipeline enforced by ESLint, atomic-design components tested for accessibility with jest-axe on every commit, and compound-component patterns built to support white-label theming across teams without duplicating logic.
